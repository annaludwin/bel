# BeL — meal planner

Weekly meal planner in **HTML, CSS, and vanilla JavaScript**. Early learning project: DOM, data, and UI without a framework.

Plans meals for Saturday–Monday and Tuesday–Friday (breakfast and other slots), with a local meal base.

## Open locally

Open `index.html` in a browser, or from the project folder:

```bash
npx --yes serve .
```

## Layout

| File | What it is |
|------|------------|
| `index.html` | Structure of the week view |
| `BELL.js` | UI behaviour |
| `mealBase.js` | Meal data |
| `styles.css` / `reset.css` | Layout and look |

Built while learning JavaScript.
